# Ingestion admission refusal

## Trigger

Manual reconciliation is initiated.

## Outcome

Missing or mismatched configured admin proof receives HTTP 401; admitted proof with wrong origin receives HTTP 403. The attempt performs no corpus effects.

## Edge cases

- Replacement is per-file atomic, not one corpus-wide transaction.
- A fatal or aborted run skips ordinary success notification; a later successful run reconciles derived state.
